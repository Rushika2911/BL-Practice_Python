modularization- breaking code into smaller modules or functions
-it can be achieved through various ways: functions, class, modules, packages, if else , loops etc.
-(:) and indentation defines the scope of code block and provide structure for modularization


functions- resuable block of code which runs only when called.
-default datatype can be any for proper useage we annotate the datatype
-there is no concept of primitive or dervided datatype as everything is objects
-it is a good practice to annotate function with proper datatype but it doesnot mean python restricts to use any other datatype as agruments. it is just a hint for better understanding of code and to avoid confusion.


-hard coding values in programs makes it static and less dynamic
-when code is compiled into byte code these hard coded values are treated as constants and can't be changed at runtime
-it is better practice to use input() function to take values from user and use them in the program. this makes the program dynamic and more interactive.
